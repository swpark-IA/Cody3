# 나만의 프롬프트 관리

파이썬 기본 문법만으로 만든 **콘솔 기반 프롬프트 관리 프로그램**입니다.
GenAI 미션에서 작성한 프롬프트를 카테고리별로 분류하고, 검색하고, 즐겨찾기로 관리합니다.
(필수 범위는 외부 라이브러리를 사용하지 않으며, 데이터는 프로그램 실행 중에만 유지됩니다.)

## 실행 방법

Python 3.10 이상이 필요합니다.

```bash
git clone https://github.com/swpark-IA/Cody3.git
cd Cody3
python main.py        # macOS/Linux는 python3 main.py
```

## 기능 목록

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리 입력 (빈 값이면 재입력, 즐겨찾기 기본값 False) |
| 2 | 프롬프트 목록 | 번호, 카테고리, 제목, 즐겨찾기(⭐) 표시 |
| 3 | 카테고리별 조회 | 선택한 카테고리의 프롬프트만 출력 |
| 4 | 프롬프트 검색 | 제목 또는 내용에 키워드가 포함된 프롬프트 검색 (대소문자 무시) |
| 5 | 프롬프트 상세 보기 | 제목, 카테고리, 즐겨찾기, 내용 전체 출력 |
| 6 | 즐겨찾기 관리 | 번호로 즐겨찾기 추가/해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아 보기 |
| 0 | 종료 | 프로그램 종료 |

## 프롬프트 카테고리

| 카테고리 | 용도 |
|---|---|
| 텍스트 생성 | 글쓰기, 요약, 이메일 등 텍스트 결과물을 만드는 프롬프트 |
| 이미지 생성 | 이미지 생성 AI용 키워드와 지시문 |
| 영상 생성 | 영상 스크립트, 영상 생성 AI용 지시문 |
| 페르소나 | AI에게 역할과 말투를 부여하는 설계안 |
| 자동화 | 노코드 자동화 워크플로에 쓰는 프롬프트 |
| 기타 | 위에 속하지 않는 프롬프트 (추가 시 직접 입력한 카테고리도 사용 가능) |

## 데이터 구조

```python
prompts = [
    {"title": "...", "content": "...", "category": "텍스트 생성", "favorite": True},
]
```

## 코드 구조

| 함수 | 역할 |
|---|---|
| `show_menu()` / `main()` | 메뉴 출력과 메인 루프 |
| `get_input()` / `get_number()` / `select_category()` | 입력 검증 헬퍼 |
| `add_prompt()` | 프롬프트 추가 |
| `show_list()` / `print_prompts()` / `format_line()` | 목록 출력 |
| `show_by_category()` | 카테고리별 조회 |
| `search_prompt()` | 검색 |
| `show_detail()` | 상세 보기 |
| `toggle_favorite()` / `show_favorites()` | 즐겨찾기 관리와 목록 |
